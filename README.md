<h2>Project Overview</h2>
<p>
  Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
  This project demonstrates the use of <strong>Grunt</strong> as a task runner.
  It includes configuration for compiling <strong>LESS</strong> into CSS and
  minifying JavaScript files with <strong>Uglify</strong>.
</p>
<h2>Technologies Used</h2>
<ul>
  <li>JavaScript</li>
  <li>Grunt</li>
  <li>LESS</li>
  <li>Uglify (JavaScript minification)</li>
</ul>
<h2>How to Run</h2>
<ol>
  <li>Clone the repository.</li>
  <li>Install dependencies with <code>npm install</code>.</li>
  <li>Run the default Grunt task with <code>npm run grunt</code> to compile LESS and minify JavaScript.</li>
  <li>Compiled files will be available in the <code>dev</code> folder.</li>
</ol>
