<h2>Visão Geral do Projeto</h2>
<p>
  This README is also available in <a href="./README.md">English</a>.
</p>
<p>
  Este projeto demonstra o uso do <strong>Grunt</strong> como task runner.
  Ele inclui a configuração para compilar <strong>LESS</strong> em CSS e
  minificar arquivos JavaScript com o <strong>Uglify</strong>.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
  <li>JavaScript</li>
  <li>Grunt</li>
  <li>LESS</li>
  <li>Uglify (minificação de JavaScript)</li>
</ul>
<h2>Como Executar</h2>
<ol>
  <li>Clone o repositório.</li>
  <li>Instale as dependências com <code>npm install</code>.</li>
  <li>Execute a tarefa padrão do Grunt com <code>npm run grunt</code> para compilar o LESS e minificar o JavaScript.</li>
  <li>Os arquivos compilados estarão disponíveis na pasta <code>dev</code>.</li>
</ol>
